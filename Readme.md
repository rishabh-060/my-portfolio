# Rishabh Verma - Full Stack Developer Portfolio

Professional portfolio website for Rishabh Verma, a Full Stack Developer focused on React.js, Node.js, REST APIs, MSSQL, MongoDB, and production web application development.

## Live Site

[https://rishabh-060.netlify.app/](https://rishabh-060.netlify.app/)

## Overview

This portfolio is a static site built with HTML, Tailwind CSS via CDN, Remix Icons, custom CSS, and GSAP animations. It uses a dark-first responsive design, smooth navigation, recruiter-friendly content sections, featured projects, direct contact actions, and a downloadable resume.

## Sections

- Hero with Full Stack Developer positioning
- About and recruiter snapshot
- Professional experience timeline
- Categorized technical skills
- Featured and GitHub-backed projects
- Education
- Direct contact actions
- Dynamic footer year

## Project Coverage

The projects section highlights Scan My Meal, Blo-Docs, Job Scheduler & Automation System, React Leaderboard, Recipe Center, Check Weather, and Employee Management System with source links and live links where a working public URL is available.
